# React + TypeScript + Vite

Projekt React utworzony z Vite i TypeScript.

## Funkcje

- ⚡ **Vite** - Szybki build tool z natychmiastowym HMR
- ⚛️ **React 18** - Najnowsza wersja React
- 📘 **TypeScript** - Pełne wsparcie typowania
- 🎨 **ESLint** - Linting kodu
- 🧩 **Prosty komponent startowy** - Gotowy szablon do rozpoczęcia pracy

## Instalacja

```bash
npm install
```

## Uruchomienie

```bash
npm run dev
```

Aplikacja będzie dostępna pod adresem `http://localhost:5173`

## Dostępne komendy

- `npm run dev` - Uruchamia serwer deweloperski
- `npm run build` - Buduje aplikację produkcyjną
- `npm run lint` - Sprawdza kod za pomocą ESLint
- `npm run preview` - Podgląd zbudowanej aplikacji

## Struktura projektu

```
├── public/          # Pliki statyczne
├── src/
│   ├── components/  # Komponenty React
│   ├── App.tsx      # Główny komponent
│   ├── App.css      # Style dla App
│   ├── main.tsx     # Punkt wejścia
│   └── index.css    # Globalne style
├── index.html       # HTML template
├── tsconfig.json    # Konfiguracja TypeScript
└── vite.config.ts   # Konfiguracja Vite
```
